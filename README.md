# SpaceShooter_DV_UNIR
Repositorio para la actividad Space Shooter para la asignatura Desarrollo de Videojuegos I

## Contenidos Actividad
- Conceptos del curso inicial
- Conceptos del Tema 1 de la asignatura
- Tema 2 de la asignatura
- Contenido extra de las clases

### Cómo se juega
- Mover nave: *WSAD* o *flechas*
- Disparar: *Espacio*
- Pausar juego: *ESC*

Para ganar, se tendrán que superar las 15 rondas del juego repartidas en 5 niveles de 3 rondas cada uno.
